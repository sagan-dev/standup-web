תמיכה

תשובות לשאלות נפוצות. עדיין תקוע? כתוב אל michal@sagan.dev.

Standup לא מוצא את השולחן שלי

נסה את הצעדים הבאים בסדר הזה:

  1. סגור כל אפליקציה אחרת המחוברת לשולחן (אפליקציה בטלפון, מאק אחר). השולחן מתקשר עם מכשיר אחד בכל פעם.
  2. אשר גישת Bluetooth ל-Standup בהגדרות המערכת ← פרטיות ואבטחה ← Bluetooth.
  3. בדוק ששם השולחן ב-Bluetooth עדיין מכיל את המילה ״Desk״.
  4. אפס את השולחן: הנמך אותו עד הסוף, החזק את כפתור ההנמכה עד שהשולחן מזנק מעלה ומטה, ואז החזק את כפתור ה-Bluetooth בבקר עד שהחיווי מתחיל להבהב, ופתח את Standup מחדש.
איך אני משתמש בפגישות Outlook?

Standup קורא את יומן macOS. הוסף את חשבון Outlook, Exchange או Microsoft 365 שלך בהגדרות המערכת ← חשבונות אינטרנט ובדוק שהאפשרות ׳יומנים׳ מופעלת עבורו. החשבון יופיע אז באפליקציית היומן ו-Standup יראה את הפגישות שבו. אשר גישה ליומן כש-Standup יבקש זאת.

אילו פגישות מרימות את השולחן?

פגישות שיש להן משתתפים נוספים, שמכילות קישור לפגישה מקוונת (Teams, Meet, Zoom, Webex, Whereby או GoToMeeting) בכתובת, במיקום או בהערות, ושאתה מארגן או אישרת. אירועים של יום שלם, הזמנות שבוטלו, נדחו, סומנו כ״אולי״ או שלא נענו, וכן אירועים המסומנים כ״פנוי״ — מתעלמים מהם. השולחן מתחיל לעלות כמה דקות לפני ההתחלה (אפשר לשנות את זמן ההקדמה בהעדפות).

למה השולחן לא זז לפגישה שלי?

בדוק שהתכונה מופעלת (Stand during meetings), שהפגישה עומדת בכללים שלמעלה, ושהשולחן מחובר. אם הנמכת את השולחן בעצמך במהלך פגישה, Standup לא ירים אותו שוב לאותה פגישה.

מה הנדנוד הקטן הזה לפני שהשולחן זז?

לפני תנועה אוטומטית השולחן מנדנד פעמיים בכיוון שאליו הוא עומד לנוע ומחכה שנייה, כך שהוא לעולם לא זז בלי אזהרה. כבה זאת בהעדפות באמצעות Nudge the desk before it moves. תנועות שאתה מתחיל בעצמך הן תמיד מיידיות.

מה עושה זיהוי השיחות, והאם האודיו שלי מוקלט?

אם תפעיל את Keep raised while on a call, השולחן יישאר למעלה אחרי הסיום המתוכנן כל עוד אפליקציית פגישות משתמשת במיקרופון או ברמקול, ויירד זמן קצר אחרי שהם משתתקים. Standup רואה רק את העובדה שאפליקציה משתמשת באודיו ואיזו אפליקציה — הוא לעולם לא מקליט ולא ניגש לאודיו או וידאו כלשהם, והוא לא מבקש הרשאת מיקרופון או מצלמה.

השולחן נעצר קצת לפני או קצת אחרי גובה ההגדרה הקבועה שלי

Standup לומד כמה השולחן שלך ממשיך לנוע אחרי עצירה ומתקן את עצמו תוך כמה תנועות. אם הסטייה נשארת גדולה מכחצי סנטימטר, כתוב לנו עם שני הגבהים.

האם אפשר לשלוט בשולחן מסקריפט או מ-Shortcuts?

כן. Standup מבין את פקודות ה-AppleScript הבאות:

tell application "Standup" to move desk "stand"    -- או "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- או "48in", או סתם "80"

ב-Shortcuts, הוסף פעולת Run AppleScript עם אחת מהשורות האלה. macOS ישאל פעם אחת לאישור לשלוט ב-Standup.

איך מפעילים את Standup בעת הכניסה למערכת, או סוגרים אותו?

פתח את Preferences מתפריט ה-״…״ בחלון הקופץ והפעל את Open at login. בחר Quit מאותו תפריט כדי לסגור את האפליקציה.
