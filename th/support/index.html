Standup หาโต๊ะของฉันไม่เจอ

ลองทำตามลำดับนี้:

  1. ปิดแอปอื่นที่เชื่อมต่อกับโต๊ะอยู่ (แอปบนโทรศัพท์ หรือ Mac อีกเครื่อง) เพราะโต๊ะสื่อสารกับอุปกรณ์ได้ทีละเครื่องเท่านั้น
  2. อนุญาตให้ Standup ใช้ Bluetooth ได้ใน การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → Bluetooth
  3. ตรวจสอบว่าชื่อโต๊ะที่ปรากฏใน Bluetooth ยังมีคำว่า "Desk" อยู่
  4. รีเซ็ตโต๊ะ: ลดโต๊ะลงจนสุด กดปุ่มลดระดับค้างไว้จนโต๊ะกระตุกลงแล้วขึ้น จากนั้นกดปุ่ม Bluetooth บนตัวควบคุมค้างไว้จนไฟกะพริบ แล้วเปิด Standup ขึ้นมาใหม่
ใช้งานการประชุมจาก Outlook ได้อย่างไร

Standup อ่านข้อมูลจากแอป Calendar ของ macOS ให้เพิ่มบัญชี Outlook, Exchange หรือ Microsoft 365 ของคุณใน การตั้งค่าระบบ → บัญชีอินเทอร์เน็ต และตรวจสอบว่าเปิดใช้งาน Calendars สำหรับบัญชีนั้นแล้ว จากนั้นบัญชีจะปรากฏในแอป Calendar และ Standup จะมองเห็นการประชุมของบัญชีนั้น อนุญาตให้เข้าถึงปฏิทินเมื่อ Standup ขอสิทธิ์

การประชุมแบบไหนที่จะทำให้โต๊ะยกขึ้น

การประชุมที่มีผู้เข้าร่วมคนอื่น มีลิงก์ประชุมออนไลน์ (Teams, Meet, Zoom, Webex, Whereby หรือ GoToMeeting) อยู่ใน URL ตำแหน่งที่ตั้ง หรือบันทึกย่อ และเป็นการประชุมที่คุณเป็นผู้จัดหรือได้ตอบรับไว้ กิจกรรมแบบทั้งวัน การประชุมที่ถูกยกเลิก ปฏิเสธ ตอบรับแบบไม่แน่ใจ หรือยังไม่ตอบรับ รวมถึงกิจกรรมที่ระบุว่า "ว่าง" จะถูกข้ามไป โต๊ะจะเริ่มยกขึ้นก่อนเวลาเริ่มไม่กี่นาที (สามารถเปลี่ยนระยะเวลาล่วงหน้านี้ได้ในหน้า Preferences)

ทำไมโต๊ะไม่ขยับในการประชุมของฉัน

ตรวจสอบว่าเปิดใช้ฟีเจอร์นี้แล้ว (Stand during meetings) การประชุมตรงตามเงื่อนไขข้างต้น และโต๊ะเชื่อมต่ออยู่ หากคุณลดโต๊ะลงเองระหว่างการประชุม Standup จะไม่ยกโต๊ะขึ้นอีกสำหรับการประชุมนั้น

สัญญาณขยับเบา ๆ ก่อนโต๊ะเคลื่อนคืออะไร

ก่อนการขยับโดยอัตโนมัติ โต๊ะจะขยับเบา ๆ สองครั้งไปในทิศทางที่กำลังจะเคลื่อน แล้วหยุดรอหนึ่งวินาที เพื่อไม่ให้ขยับโดยไม่มีการเตือนล่วงหน้า ปิดการใช้งานได้ในหน้า Preferences ที่ตัวเลือก Nudge the desk before it moves ส่วนการขยับที่คุณสั่งเองจะเกิดขึ้นทันทีเสมอ

การตรวจจับสายทำงานอย่างไร และเสียงของฉันถูกบันทึกหรือไม่

หากคุณเปิดใช้ Keep raised while on a call โต๊ะจะคงอยู่ในตำแหน่งยืนต่อไปหลังเวลาสิ้นสุดที่กำหนดไว้ ตราบใดที่แอปประชุมยังใช้ไมโครโฟนหรือลำโพงอยู่ และจะลดลงไม่นานหลังจากเสียงหยุดลง Standup รู้เพียงว่ามีแอปกำลังใช้เสียงอยู่และแอปไหน — ไม่มีการบันทึกหรือเข้าถึงเสียงหรือวิดีโอใด ๆ เลย และไม่มีการขอสิทธิ์เข้าถึงไมโครโฟนหรือกล้อง

โต๊ะหยุดก่อนหรือเกินความสูงที่ตั้งไว้เล็กน้อย

Standup จะเรียนรู้ว่าโต๊ะของคุณเลื่อนต่อไปอีกเท่าไรหลังจากหยุด และจะปรับให้แม่นยำขึ้นเองหลังจากขยับไม่กี่ครั้ง หากยังคลาดเคลื่อนมากกว่าประมาณครึ่งเซนติเมตร ส่งอีเมลมาแจ้งเราพร้อมระบุความสูงทั้งสองค่า

ควบคุมโต๊ะจากสคริปต์หรือ Shortcuts ได้หรือไม่

ได้ Standup เข้าใจคำสั่ง AppleScript เหล่านี้:

tell application "Standup" to move desk "stand"    -- หรือ "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- หรือ "48in", หรือใส่แค่ "80"

ใน Shortcuts ให้เพิ่มแอ็กชัน Run AppleScript แล้วใส่หนึ่งในบรรทัดเหล่านั้น macOS จะขอสิทธิ์ควบคุม Standup เพียงครั้งเดียว

เปิด Standup อัตโนมัติเมื่อเข้าสู่ระบบ หรือจะปิดแอปได้อย่างไร

เปิด Preferences จากเมนู "…" ในป๊อปอัป แล้วเปิดใช้งาน Open at login เลือก Quit จากเมนูเดียวกันเพื่อปิดแอป
