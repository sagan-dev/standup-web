Kebijakan Privasi

Berlaku mulai 29 September 2026

Singkatnya: Standup tidak mengumpulkan data pribadi apa pun. Tidak ada akun, analitik, pelacakan, atau server. Semua yang dilakukan aplikasi ini tetap berada di Mac Anda.

Siapa yang bertanggung jawab

Standup - Desk Remote Control dikembangkan oleh Michal Sagan (sagan.dev). Kontak: michal@sagan.dev.

Apa yang diakses aplikasi, dan mengapa

  • Bluetooth. Hanya digunakan untuk menemukan dan berkomunikasi dengan meja Anda (membaca tingginya, mengirim perintah gerak). Tidak ada yang dikirim ke tempat lain.
  • Kalender (hanya jika Anda mengaktifkan fitur rapat). Standup membaca acara kalender Anda secara lokal, melalui EventKit milik Apple, untuk menemukan rapat online yang Anda selenggarakan atau terima. Data acara digunakan pada perangkat untuk memutuskan kapan menggerakkan meja. Data ini tidak pernah disimpan di luar kalender sistem, tidak pernah diunggah, dan tidak pernah dibagikan. Ini termasuk akun seperti Outlook, Exchange, atau Microsoft 365 yang telah Anda tambahkan ke macOS.
  • Aktivitas audio (hanya jika Anda mengaktifkan deteksi panggilan). Standup hanya menanyakan kepada macOS apakah sebuah aplikasi sedang menggunakan input audio (mikrofon) atau output (speaker), dan aplikasi mana. Aplikasi ini tidak menangkap, merekam, mendengarkan, atau mengakses audio atau video apa pun, dan tidak meminta izin mikrofon atau kamera.
  • Notifikasi (opsional). Notifikasi lokal, misalnya saran untuk menaikkan meja saat panggilan tak terjadwal. Notifikasi ini dibuat di Mac Anda dan tidak dikirim melalui server apa pun.
  • Pengaturan. Preferensi Anda (tinggi, satuan, opsi) disimpan secara lokal di Mac Anda dalam preferensi aplikasi. Data ini tidak disinkronkan atau diunggah.

Apa yang tidak kami lakukan

  • Tidak ada data pribadi yang dikumpulkan, dikirim, dijual, atau dibagikan.
  • Tidak ada SDK analitik, iklan, pelacakan, profil, atau pelaporan crash. Aplikasi ini tidak mengandung SDK pihak ketiga; helper buka-saat-login adalah komponen sumber terbuka lokal yang kecil.
  • Tidak ada akun pengguna dan tidak ada server yang kami operasikan untuk aplikasi ini. Aplikasi ini bekerja sepenuhnya secara offline.

Retensi data dan kendali Anda

Karena tidak ada yang keluar dari Mac Anda, tidak ada data yang kami simpan untuk diakses, dikoreksi, atau dihapus. Pengaturan lokal dapat dihapus dengan mengatur ulang preferensi aplikasi atau mencopot pemasangannya. Anda dapat mencabut akses Bluetooth, Kalender, atau Notifikasi kapan saja di Pengaturan Sistem → Privasi & Keamanan, dan mematikan fitur rapat, deteksi panggilan, dan saran di Preferensi.

GDPR

Standup tidak memproses data pribadi di server mana pun milik kami, sehingga tidak ada pemrosesan di pihak kami yang dapat menjadi subjek permintaan akses, perbaikan, penghapusan, atau portabilitas data. Jika Anda memiliki pertanyaan, tulis ke michal@sagan.dev. Anda juga memiliki hak untuk mengajukan keluhan kepada otoritas pelindungan data Anda.

Situs web ini

standup.sagan.dev adalah situs web statis. Situs ini tidak memasang cookie dan tidak menjalankan analitik. Seperti layanan hosting web lainnya, penyedia hosting (Vercel) dapat memproses log server teknis seperti alamat IP untuk menyajikan dan mengamankan situs.

Anak-anak

Standup adalah aplikasi utilitas dan tidak ditujukan untuk anak-anak. Aplikasi ini tidak secara sengaja mengumpulkan data dari siapa pun.

Perubahan

Jika kebijakan ini berubah, versi baru akan dipublikasikan di halaman ini dengan tanggal yang diperbarui.
