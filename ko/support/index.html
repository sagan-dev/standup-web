Standup이 내 책상을 찾지 못해요

다음 순서대로 시도해 보세요:

  1. 책상에 연결된 다른 앱(휴대폰 앱, 다른 Mac 등)을 모두 종료하세요. 책상은 한 번에 하나의 기기와만 통신합니다.
  2. 시스템 설정 → 개인정보 보호 및 보안 → 블루투스에서 Standup의 블루투스 접근을 허용하세요.
  3. 블루투스에 표시되는 책상 이름에 여전히 "Desk"라는 단어가 포함되어 있는지 확인하세요.
  4. 책상을 초기화하세요: 책상을 최대한 내린 뒤, 내리기 버튼을 책상이 한 번 아래로 내려갔다가 다시 위로 튀어 오를 때까지 누르고 있다가, 컨트롤러의 블루투스 버튼을 불빛이 깜박일 때까지 누르고 있은 다음, Standup을 다시 여세요.
Outlook 회의는 어떻게 사용하나요?

Standup은 macOS 캘린더를 읽습니다. 시스템 설정 → 인터넷 계정에서 Outlook, Exchange 또는 Microsoft 365 계정을 추가하고 해당 계정의 캘린더가 켜져 있는지 확인하세요. 그러면 해당 계정이 캘린더 앱에 표시되고 Standup이 그 회의를 볼 수 있습니다. Standup이 요청할 때 캘린더 접근을 허용하세요.

어떤 회의에서 책상이 올라가나요?

다른 참석자가 있고, URL이나 위치, 메모에 온라인 회의 링크(Teams, Meet, Zoom, Webex, Whereby 또는 GoToMeeting)가 포함되어 있으며, 사용자가 주최했거나 참석을 수락한 회의입니다. 종일 일정, 취소됨, 거절함, 미정 또는 응답하지 않은 초대, "여유"로 표시된 일정은 무시됩니다. 책상은 시작 몇 분 전부터 올라가기 시작합니다(이 시간은 설정에서 변경할 수 있습니다).

왜 회의 때 책상이 움직이지 않았나요?

해당 기능(Stand during meetings)이 켜져 있는지, 회의가 위 규칙에 맞는지, 책상이 연결되어 있는지 확인하세요. 회의 중에 직접 책상을 내렸다면, Standup은 그 회의에 대해 다시 책상을 올리지 않습니다.

책상이 움직이기 전의 작은 넛지는 무엇인가요?

자동으로 움직이기 전에 책상은 이동할 방향으로 두 번 살짝 움직인 뒤 1초를 기다리므로, 예고 없이 움직이는 일은 없습니다. 설정의 Nudge the desk before it moves에서 끌 수 있습니다. 직접 시작한 이동은 항상 즉시 이루어집니다.

통화 감지는 무엇을 하며, 제 오디오가 녹음되나요?

Keep raised while on a call을 켜면, 회의 앱이 여전히 마이크나 스피커를 사용하는 동안 예정된 종료 시간이 지나도 책상이 올라간 상태를 유지하고, 사용이 멈추면 곧 내려갑니다. Standup은 어떤 앱이 오디오를 사용하고 있다는 사실과 어떤 앱인지만 확인할 뿐, 오디오나 영상을 녹음하거나 접근하는 일은 전혀 없으며 마이크나 카메라 권한을 요청하지도 않습니다.

책상이 설정한 높이보다 조금 모자라거나 조금 지나쳐서 멈춰요

Standup은 멈춘 뒤 책상이 얼마나 더 움직이는지를 학습해 몇 번의 이동 후 스스로 보정합니다. 그래도 약 0.5cm 이상 차이가 계속된다면 두 높이 값을 알려주며 저희에게 연락해 주세요.

스크립트나 단축어로 책상을 제어할 수 있나요?

네. Standup은 다음 AppleScript 명령을 이해합니다:

tell application "Standup" to move desk "stand"    -- 또는 "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- 또는 "48in", 또는 그냥 "80"

단축어에서는 이 줄 중 하나로 AppleScript 실행 동작을 추가하세요. macOS는 Standup을 제어할 권한을 한 번만 물어봅니다.

Standup을 로그인 시 자동 실행하거나 종료하려면 어떻게 하나요?

팝오버의 "…" 메뉴에서 설정을 열고 Open at login을 켜세요. 앱을 닫으려면 같은 메뉴에서 Quit을 선택하세요.
