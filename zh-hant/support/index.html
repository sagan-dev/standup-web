Standup 找不到我的桌子

請依序嘗試以下方法:

  1. 關閉所有其他連接到桌子的應用程式(手機應用程式、另一台 Mac 等)。桌子一次只能與一個裝置通訊。
  2. 在系統設定 → 隱私權與安全性 → 藍牙中允許 Standup 使用藍牙。
  3. 確認藍牙中顯示的桌子名稱仍包含單字「Desk」。
  4. 重設桌子:將它降到最低,按住降低按鈕,直到桌子先向下再向上跳動一下,然後按住控制器上的藍牙按鈕,直到指示燈閃爍,再重新打開 Standup。
如何使用 Outlook 會議?

Standup 讀取的是 macOS 行事曆。請在系統設定 → 網際網路帳號中新增你的 Outlook、Exchange 或 Microsoft 365 帳戶,並確保已為其開啟行事曆功能。該帳戶隨後會顯示在行事曆應用程式中,Standup 就能看到其中的會議。當 Standup 要求時,請允許行事曆存取權限。

哪些會議會升起桌子?

有其他與會者參加,且在網址、地點或備註中包含線上會議連結(Teams、Meet、Zoom、Webex、Whereby 或 GoToMeeting),並且是你組織或已接受的會議。全天事件、已取消、已拒絕、暫定或未回覆的邀請,以及標記為「空閒」的事件都會被忽略。桌子會在會議開始前幾分鐘開始升起(可在偏好設定中更改提前時間)。

為什麼開會時桌子沒有升起?

請檢查該功能(Stand during meetings)是否已開啟、會議是否符合上述規則,以及桌子是否已連線。如果你在會議期間自己把桌子降下,Standup 不會再為該會議升起桌子。

桌子移動前的小幅擺動是什麼?

在自動移動之前,桌子會先朝即將移動的方向輕輕擺動兩次,再等待一秒,這樣它絕不會毫無預警地移動。你可以在偏好設定的Nudge the desk before it moves中關閉此功能。你自己發起的移動始終是立即執行的。

通話偵測是做什麼的?我的音訊會被錄製嗎?

如果你開啟Keep raised while on a call,那麼在會議應用程式仍在使用麥克風或喇叭時,桌子會在預定結束時間之後繼續保持升起狀態,並在聲音停止使用後不久降下。Standup 只能知道某個應用程式正在使用音訊以及是哪個應用程式 — 它絕不會錄製或存取任何音訊或視訊內容,也不會要求麥克風或相機權限。

桌子停止的位置比預設高度稍高或稍低

Standup 會學習你的桌子在停止後還會繼續滑動多遠,並在幾次移動後自動校正。如果偏差仍然超過約半公分,請將兩個高度值告訴我們。

我可以透過腳本或「捷徑」控制桌子嗎?

可以。Standup 支援以下 AppleScript 指令:

tell application "Standup" to move desk "stand"    -- 或 "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- 或 "48in", 或僅 "80"

在「捷徑」中,新增一個執行 AppleScript動作並使用其中一行程式碼。macOS 只會詢問一次是否允許控制 Standup。

如何讓 Standup 在登入時啟動,或如何退出它?

從彈出視窗的「…」選單中開啟偏好設定,並開啟Open at login。要關閉應用程式,請從同一選單中選擇Quit。
