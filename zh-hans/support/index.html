支持

常见问题解答。仍然没有解决?请写信至 michal@sagan.dev。

Standup 找不到我的桌子

请按顺序尝试以下方法:

  1. 关闭所有其他连接到桌子的应用(手机应用、另一台 Mac 等)。桌子一次只能与一个设备通信。
  2. 在系统设置 → 隐私与安全性 → 蓝牙中允许 Standup 使用蓝牙。
  3. 确认蓝牙中显示的桌子名称仍包含单词“Desk”。
  4. 重置桌子:将其降到最低,按住降低按钮,直到桌子先向下再向上跳动一下,然后按住控制器上的蓝牙按钮,直到指示灯闪烁,再重新打开 Standup。
如何使用 Outlook 会议?

Standup 读取的是 macOS 日历。请在系统设置 → 互联网账户中添加你的 Outlook、Exchange 或 Microsoft 365 账户,并确保已为其开启日历功能。该账户随后会显示在日历应用中,Standup 就能看到其中的会议。当 Standup 请求时,请允许日历访问权限。

哪些会议会升起桌子?

有其他与会者参加,且在网址、地点或备注中包含在线会议链接(Teams、Meet、Zoom、Webex、Whereby 或 GoToMeeting),并且是你组织或已接受的会议。全天事件、已取消、已拒绝、暂定或未回复的邀请,以及标记为“空闲”的事件都会被忽略。桌子会在会议开始前几分钟开始升起(可在偏好设置中更改提前时间)。

为什么开会时桌子没有升起?

请检查该功能(Stand during meetings)是否已开启、会议是否符合上述规则,以及桌子是否已连接。如果你在会议期间自己把桌子降下,Standup 不会再为该会议升起桌子。

桌子移动前的小幅摆动是什么?

在自动移动之前,桌子会先朝即将移动的方向轻轻摆动两次,再等待一秒,这样它绝不会毫无预警地移动。你可以在偏好设置的Nudge the desk before it moves中关闭此功能。你自己发起的移动始终是立即执行的。

通话检测是做什么的?我的音频会被录制吗?

如果你开启Keep raised while on a call,那么在会议应用仍在使用麦克风或扬声器时,桌子会在计划结束时间之后继续保持升起状态,并在声音停止使用后不久降下。Standup 只能知道某个应用正在使用音频以及是哪个应用 — 它绝不会录制或访问任何音频或视频内容,也不会请求麦克风或摄像头权限。

桌子停止的位置比预设高度稍高或稍低

Standup 会学习你的桌子在停止后还会继续滑动多远,并在几次移动后自动校正。如果偏差仍然超过约半厘米,请将两个高度值发给我们。

我可以通过脚本或「快捷指令」控制桌子吗?

可以。Standup 支持以下 AppleScript 命令:

tell application "Standup" to move desk "stand"    -- 或 "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- 或 "48in", 或仅 "80"

在「快捷指令」中,添加一个运行 AppleScript操作并使用其中一行代码。macOS 只会询问一次是否允许控制 Standup。

如何让 Standup 在登录时启动,或如何退出它?

从弹出窗口的“…”菜单中打开偏好设置,并开启Open at login。要关闭应用,请从同一菜单中选择Quit。
