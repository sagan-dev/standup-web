サポート

よくある質問への回答です。解決しない場合はmichal@sagan.devまでご連絡ください。

Standupがデスクを見つけられない

次の順番で試してください:

  1. デスクに接続している他のアプリ(スマートフォンのアプリ、別のMacなど)を終了してください。デスクは一度に1台のデバイスとしか通信できません。
  2. システム設定 → プライバシーとセキュリティ → BluetoothでStandupのBluetoothを許可してください。
  3. Bluetoothに表示されるデスクの名前に「Desk」という単語が含まれているか確認してください。
  4. デスクをリセットします:デスクを一番下まで下げ、下げるボタンを押し続けてデスクが一度下がって上がるまで待ち、次にコントローラーのBluetoothボタンをランプが点滅するまで押し続けてから、もう一度Standupを開いてください。
Outlookの会議はどうすれば使えますか?

StandupはmacOSのカレンダーを読み取ります。システム設定 → インターネットアカウントでOutlook、Exchange、Microsoft 365のアカウントを追加し、そのアカウントのカレンダーがオンになっていることを確認してください。すると、そのアカウントがカレンダーアプリに表示され、Standupがその会議を認識できるようになります。Standupから確認を求められたら、カレンダーへのアクセスを許可してください。

どの会議でデスクが上がりますか?

他の参加者がいて、URL、場所、またはメモにオンライン会議のリンク(Teams、Meet、Zoom、Webex、Whereby、GoToMeetingなど)が含まれており、自分が主催しているか参加を承諾した会議です。終日の予定、キャンセル済み、辞退、仮承諾、未回答の予定、および「空き」として表示されている予定は無視されます。デスクは開始の数分前から上がり始めます(事前の時間は環境設定で変更できます)。

会議でデスクが動かなかったのはなぜですか?

機能(Stand during meetings)がオンになっているか、会議が上記の条件を満たしているか、デスクが接続されているかを確認してください。会議中に自分でデスクを下げた場合、Standupはその会議では再びデスクを上げません。

デスクが動く前の小さな合図は何ですか?

自動で動く前に、デスクはこれから進む方向へ2回小さく動き、1秒待ちます。これにより予告なしに動くことはありません。環境設定のNudge the desk before it movesでオフにできます。自分で操作して動かす場合は常に即時に動きます。

通話検知とは何ですか?音声は録音されますか?

Keep raised while on a callをオンにすると、会議アプリがまだマイクまたはスピーカーを使用している間は予定終了後もデスクが上がったままになり、使用が止まるとすぐに下がります。Standupが確認するのは、アプリが音声を使用しているという事実とどのアプリかだけです — 音声や映像を録音・アクセスすることは一切なく、マイクやカメラへのアクセス許可を求めることもありません。

デスクがプリセットの高さより少し手前または少し先で止まる

Standupは、停止後にデスクがどれだけ動くかを学習し、数回の移動で自動的に補正します。それでも約0.5cm以上ずれる場合は、2つの高さを添えてご連絡ください。

スクリプトやショートカットからデスクを操作できますか?

はい。Standupは次のAppleScriptコマンドを理解します:

tell application "Standup" to move desk "stand"    -- または "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- または "48in", または単に "80"

ショートカットでは、これらの行のいずれかを使ってAppleScriptを実行アクションを追加してください。macOSは一度だけStandupを操作する許可を求めます。

ログイン時にStandupを起動する方法、または終了する方法は?

popoverの「…」メニューから環境設定を開き、Open at loginをオンにしてください。アプリを閉じるには、同じメニューからQuitを選択してください。
